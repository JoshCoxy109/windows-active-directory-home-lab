# Windows Active Directory Home Lab

## Overview

Built a virtualized Windows/Linux environment on an Apple Silicon Mac
to develop hands-on systems administration skills.

## Objectives

- Learn Active Directory concepts
- Configure an AD-compatible domain controller
- Practice DNS and DHCP
- Create users and security groups
- Join a Windows client to a domain
- Configure Group Policy
- Practice permissions and authentication
- Troubleshoot common network and system issues

## Environment

- Apple M2 Mac
- UTM
- Windows 11 ARM64
- Ubuntu Server ARM64
- Samba Active Directory Domain Controller
